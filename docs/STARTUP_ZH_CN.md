# 首次启动与组件准备

当前分支：`codex/droiddeck-ui`。实现位于 `app/Madeira/DeckStartup.swift`。

首次打开的顺序：

1. 在一个页面中选择 **脚本 JIT** 或 **内置 JIT**。
2. 点击“继续并准备组件”，播放 DroidDeck 启动动画，同时自动准备运行组件。
3. 准备完成后进入 Steam 首页。

脚本方式可以直接导出 `madeira-jit.js`，由 StikDebug 执行；内置方式可以打开
现有的配对、导入配对文件和 LocalDevVPN 设置。LiveContainer 环境保留脚本方式，
内置选项会显示不可用原因。选择只保存一次，以后在“设置 → JIT”中更改。
JIT 的实际附加、内存准备与解除附加流程继续使用现有后端，本轮没有修改 JIT 脚本。

原来的欢迎、安装 VPN、Steam 登录、快捷指令、逐项运行库介绍及完成页已删除，
“重新运行引导”按钮已移除。Steam 登录、配对、各运行库和图形/显示设置仍在原有分类。

## 启动动画

使用 DroidDeck 0.6.9 默认的原始 `droiddeck-startup.webm`，保留原画面和音效，
转换为 iOS 原生 AVPlayer 使用的 H.264/AAC MP4。画面为 1280×720、30 帧，
共 190 帧，时长约 6.35 秒。来源提交、转码参数和哈希记录于
`droiddeck-startup-asset.json`；许可证和来源声明随动画一起打包。

后续每次冷启动播放一次；从后台返回不重播。进入后台暂停，返回后继续。
播放失败或卡住时可继续进入界面，播放器退出时释放。系统开启“减少动态效果”时跳过。
“设置 → 启动器”提供播放开关、音效开关和预览。

## 自动准备的四项组件

| 组件 | 实际动作 |
| --- | --- |
| Wine Mono | 从 WineHQ 下载固定版本，校验 SHA-256、解压并安装；已有可用版本时跳过 |
| Microsoft Visual C++ | 使用现有固定版本安装器下载、校验和 DLL 提取流程，检查已安装版本 |
| Wine Gecko | 从 WineHQ 下载并校验两个已有架构的 MSI，供 Wine 使用 |
| Madeira Dock | 检查包内 Dock 宿主，使用原有安装服务下载并校验 Valve 客户端组件 |

界面显示每项真实的下载、解压或验证状态。Dock 下载器只提供阶段文本时显示不定进度，
不生成虚构百分比。准备期间不启动 Wine，不申请 JIT 内存，不修改图形或内存池参数。

四项全部就绪才记录首次准备完成。网络或空间不足等失败会保留原因，点击“重试下载”
仅补齐缺失项。失败后可选择“稍后下载”，这不会记为成功；下次启动继续准备，
不会再问 JIT 方式。以后可从“组件”或“设置 → 启动器”重新检查并准备。

## Steam 首页

首页只显示一个“启动 Steam”操作。尚未安装交互式 Steam 客户端时，此按钮启动
原有内置 Steam 安装程序，下方说明首次安装行为；安装后启动客户端。
JIT 附加仍由原有启动检查按所选方式执行。首页不再放置独立的安装器、JIT 或 Dock 设置按钮。
侧栏和其他页面保留，以继续访问图形、显示、手柄、运行库和诊断。
